# MIPI Based LiFi Transmission

This repository contains the RTL design and testbenches for a MIPI-based LiFi transmission project.

## Directory Structure
- `rtl/`: Synthesizable Verilog modules.
- `tb/`: Testbenches for verification.
- `scripts/`: Utility scripts (e.g., Python scripts for image processing).
- `sim/`: Simulation output and waveforms (ignored in Git).
- `docs/`: Project documentation and architecture diagrams.

Work will be added to this repository on a daily basis.
